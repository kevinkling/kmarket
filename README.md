# KMarket

PWA offline-first para administrar tu despensa y preparar la compra mensual.

## Desarrollo

```bash
pnpm install
pnpm start
```

App local: http://localhost:4200/

## Deploy (GitHub Pages)

El push a `main` dispara el workflow y publica en:

**https://kevinkling.github.io/kmarket/**

Build manual:

```bash
pnpm run build:gh-pages
```
